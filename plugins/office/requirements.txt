# The office format layer's dependencies — exact pins, per the engine's own rule
# (no ranges: a range lets PyPI ship a new transitive at any time without a review).
#
# These are the libraries the vendored scripts in `office_engine/upstream/` import. They are
# installed into the engine's own interpreter by `scripts/dev-sync.sh` on a dev machine and
# staged into the desktop payload by `scripts/build-windows-payload.ps1`; the product never asks
# the operator to pip install anything.
#
# Licences (all inside the allowlist; recorded in PROVENANCE.md and scanned in CI):
#   python-docx MIT · openpyxl MIT · python-pptx MIT · lxml BSD-3 · XlsxWriter BSD-2
#   et-xmlfile MIT · typing_extensions PSF · Pillow MIT-CMU (already a core engine dependency)
#
# Pillow is pinned here because python-pptx asks for `Pillow>=3.3.2`, and a resolver without the
# engine's own constraint picks a 2021 release with a wall of published CVEs. The engine already
# ships 13.0.0; naming it keeps the closure equal to what runs.
python-docx==1.2.0
openpyxl==3.1.5
python-pptx==1.0.2
lxml==6.1.3
XlsxWriter==3.3.1
et-xmlfile==2.0.0
typing_extensions==4.16.0
pillow==13.0.0
